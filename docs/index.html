Luanti Game

Seven bosses. One arena. Graduate or die.

Memento Mori is a wave-based combat game for Luanti (Minetest 5.7+). Fight through seven waves of student enemies, each ending in a boss encounter. Survive all seven and trigger the final victory cinematic.

Install the Game Read the Docs
Overview

How the game works

Eight mods, one arena building, seven boss fights. Each system is independent and documented separately.

Wave System

Waves trigger at school break times — 10:10, 12:10, 14:15. Each wave spawns 10 student enemies. Clear them all and the boss appears.

Boss Encounters

Seven unique bosses with escalating HP and distinct attack patterns.

Trailer Mode

Built-in cinematic mode hides the player, spawns a camera entity with wall avoidance, and records clean footage without HUD clutter.
