Setup

Up and running in three steps.

Download Luanti, drop the game folder in the right place, and you're in. No build tools, no dependencies — just copy and play.

Download game_of_battle.zip Get Luanti (luanti.org)
Steps

Installation flow

Follow in order. The whole process takes about two minutes.

Step 1 — Get the engine

Download and install Luanti

Luanti (formerly Minetest) is the free, open-source engine that runs Memento Mori. Grab the latest stable release for your operating system from the official site.

luanti.org →
Step 2 — Download the game

Get the game_of_battle archive

Download the zip below, then unpack it. You will get a folder called game_of_battle. Keep it intact — do not rename it.

Download game_of_battle.zip
Step 3 — Place it in the right folder

Copy into your Luanti games directory

Move the unpacked game_of_battle folder into the games sub-folder for your OS:

Windows

%APPDATA%\minetest\games

Press Win + R, paste the path, press Enter.

Linux

~/.minetest/games

Or ~/.var/app/net.minetest.Minetest/data/minetest/games for the Flatpak.

macOS

~/Library/Application Support/minetest/games

Open Finder, press ⇧⌘G and paste the path.

Step 4 — Launch

Start Luanti and select the game

Open Luanti. On the main screen, click Start Game, then pick Memento Mori / game_of_battle from the game list. Create a new world (any map generator works) and hit Play.

The first wave starts immediately. Boss fights begin at the end of each wave. Good luck.

Reference

Requirements & troubleshooting

Everything you need to know if something goes wrong.

Requirements

  • Engine: Luanti 5.7.0 or newer (Minetest 5.7+)
  • OS: Windows 10+, any modern Linux distro, macOS 11+
  • Disk: ~50 MB unpacked
  • RAM: 512 MB minimum (1 GB recommended)
  • Dependencies: none — all mods are bundled inside the game folder

Troubleshooting

  • Game not in list: make sure the folder name is exactly game_of_battle and it sits directly inside games/, not in a sub-folder
  • Missing textures: re-extract the zip — partial extractions skip files silently
  • Bosses not spawning: enemies only appear after the wave counter starts — create a fresh world
  • Bugs / crashes: open an issue on GitHub Issues
