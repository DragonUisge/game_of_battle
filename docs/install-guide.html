Steps

Recommended installation flow

GitHub Pages is static, so keep the guide practical: where to clone, where to copy the game folder, and how to launch it from Minetest.

Step 1

Get everything

Download Minetest:

luanti.org Download the latest game archive
Step 2

Unpack the archive and place it into your Minetest games directory.

Windows: %APPDATA%\minetest\games

Linux: ~/.minetest/games

MacOS: ~/Library/Application Support/minetest/games

Copy the repository into the Minetest games folder on your system, then verify that the project root contains the expected game configuration files.

Step 3

Launch and test

Start Minetest, select the game, create or open a world, and confirm that the core content loads correctly before testing trailer mode or boss encounters.
